# Kevin Hogan — Portfolio

Static HTML portfolio using the Vibrant Tangerine palette.

## Publish with GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io` (or `portfolio` for a project site).
2. Upload the contents of this folder to the root of the repository on the `main` branch.
3. In Settings > Pages, select Deploy from a branch, then `main` and `/ (root)`, and save.
4. Open the URL shown in Settings > Pages after deployment.

Before publishing, replace placeholder project content and contact details in index.html. Google Fonts requires an internet connection; fallback fonts are included.
